## HOW TO USE IT

1. Copy the entire text block inside the triple backticks above.
2. Paste into ChatGPT (4o / 4.5 / o3 work best; 4o-mini is fine for a first pass).
3. After it writes the CV, ask follow-ups like:
   - "Make the Summary one paragraph, max 4 lines."
   - "Tighten the BerlinX experience to 3 bullets max."
   - "Add a one-line 'Selected Tools' line under the Summary."

Save this file as `prompts/update-cv-from-portfolio.md` in the repo so you can reuse it.
